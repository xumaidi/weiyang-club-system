# 未央 · 社团任务管理系统 UI

基于角色权限的社团任务管理系统 B 端界面原型，单文件 HTML + Tailwind CSS，无需构建、双击即可打开。

## 在线预览

开启 GitHub Pages 后访问：`https://xumaidi.github.io/weiyang-club-system/`

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | 入口，自动跳转到主系统 |
| `weiyang-club-system.html` | **主文件** — 三角色共 19 个页面 + 登录页的完整 SPA |
| `page1-task-management.html` | 主席团端【任务管理】单页稿 |
| `page2-signup-assignment.html` | 部长端【报名与分工】单页稿 |

## 角色与页面

登录页提供三个演示入口，不同角色生成不同的侧边栏导航。

**主席团 & 社长**：工作台、社团人员信息管理、任务管理、任务详情（部门分工 / 进度管理）、产出审核、活动及项目公告、资产管理、向下沟通

**部长**：部门人员信息管理、子任务管理、子任务详情、报名管理、分工设置、成员名单、子任务公告、向上 / 向下沟通

**成员**：任务大厅、子任务详情与报名、我的任务、我的产出、向上沟通

## 设计语言

- **玻璃拟态**：卡片 / 侧边栏 / 顶栏均为半透明冷灰 + 背景模糊，面板带 1px 内高光
- **极光背景**：三团超大柔光（冷蓝 / 淡紫 / 青）+ SVG 噪点
- **hover 光晕**：按钮悬停时对比度拉高并向外扩彩色光晕，不做压暗
- **状态色**：完成 = 黑，进行中 = 蓝，未开始 = 灰；待审核 = 琥珀，已通过 = 绿，已驳回 = 玫红
- **切屏动效**：淡出上移 → 浮现 + 分块错峰（44ms 间隔）+ 顶部进度光带，约 730ms

## 导入 Figma

三个文件都是零依赖单文件，可整份粘贴进 HTML-to-Figma 类插件；也可用浏览器打开后逐屏截图。建议顺序：登录页 → 主席团 → 部长 → 成员。

> 动效不影响静态截图，如需体现交互建议录屏附在设计稿的交互说明里。

## 技术栈

HTML5 + Tailwind CSS（CDN）+ 原生 JavaScript，无任何构建步骤与运行时依赖。
