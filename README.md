# 未央 · 社团任务管理系统 UI

基于角色权限的社团任务管理系统。M7 资产与 M8 单独沟通已接入 Cluv 后端；其余模块保留界面演示。HTML + Tailwind CSS + 原生 JavaScript，无需构建。

## M7 / M8 真实接口

通过静态服务器打开 `weiyang-club-system.html`，在登录页「后端连接设置」填写 Cluv 服务地址（默认 `http://127.0.0.1:18081`），输入真实学号和密码。后端需启用 CORS；HTTPS 页面需连接 HTTPS 后端，避免混合内容被拦截。双击文件仅适合界面预览，联调请通过 HTTP(S) 访问。

真实登录后进入资产与沟通页面；角色取服务端返回值，首次登录先改密。刷新通过 `/login/me` 恢复身份，401 返回登录页。token 仅存当前标签页 `sessionStorage`，不保存密码；后端地址存 `localStorage`。退出时清除本地凭证并调用注销接口，服务端注销失败会提示。

| 功能 | 社长 / 主席团 | 部长 | 成员 |
| --- | --- | --- | --- |
| 资产列表、总量 / 可用量 / 已分配量 | 查看 | 查看 | 查看 |
| 新增、编辑资产 | 支持 | — | — |
| 资产使用申请 | — | 提交并查看自己的申请 | — |
| 同意 / 驳回申请与意见 | 支持 | 查看结果 | — |
| 单独沟通 | 部长、成员 | 社长、主席团、本部门成员 | 社长、主席团、本部门现任部长 |

资产与申请按服务端分页，保存后重新读取库存。消息支持联系人姓名搜索与分页、复用会话、纯文本收发、更早历史、约 2 秒轮询及 ID 去重。发送结果不直接推进轮询游标，避免漏掉同时到达的消息；切换联系人、离开页面和退出时停止旧会话。网络失败保留草稿，发送结果不明时需核对记录后手动确认重发，不自动重试。

依赖 [Cluv](https://github.com/trancecho/Cluv) 的 M1/M2/M7/M8 及本次配套 PR 新增的 `GET /api/v1/message/contacts`。缺少接口时显示错误，不以演示数据替代。接口文档统一维护于后端 `Internal/asset/docs/api.md` 和 `Internal/message/docs/api.md`；模块说明为各自的 `README.md`。

新增代码：`scripts/club-api.js`（请求和游标）、`scripts/m7-m8.js`（页面交互）、`styles/m7-m8.css`（小屏布局）。

## 角色与页面

登录页另提供三个其他模块的界面演示入口，不同角色生成不同的侧边栏导航。演示模式进入 M7/M8 时提示使用真实账号登录。

**主席团 & 社长**：工作台、社团人员信息管理、任务管理、任务详情（部门分工 / 进度管理）、产出审核、活动及项目公告、资产管理、向下沟通

**部长**：部门人员信息管理、子任务管理、子任务详情、报名管理、分工设置、成员名单、子任务公告、向上 / 向下沟通

**成员**：任务大厅、子任务详情与报名、我的任务、我的产出、向上沟通

## 设计语言

- **玻璃拟态**：卡片 / 侧边栏 / 顶栏均为半透明冷灰 + 背景模糊，面板带 1px 内高光
- **极光背景**：三团超大柔光（冷蓝 / 淡紫 / 青）+ SVG 噪点
- **hover 光晕**：按钮悬停时对比度拉高并向外扩彩色光晕，不做压暗
- **状态色**：完成 = 黑，进行中 = 蓝，未开始 = 灰；待审核 = 琥珀，已通过 = 绿，已驳回 = 玫红
- **切屏动效**：淡出上移 → 浮现 + 分块错峰（44ms 间隔）+ 顶部进度光带，约 730ms
