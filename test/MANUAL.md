# M7 / M8 浏览器联调

使用 README 的隔离后端服务，通过真实 M1/M2/M7/M8 模块完成以下操作。

1. `ui1` 登录，新增资产总数 6，编辑名称与总量，翻到第二页再返回；刷新确认身份恢复、资产保留。
2. `ui3` 登录：无新增和编辑按钮。申请上述资产 2 件并填写用途，自己的列表出现待审批；提交时可用量仍为 6。
3. `ui1` 刷新并同意申请、填写意见，可用量变 4、已分配变 2；`ui3` 刷新看到结果。再次申请并驳回，库存不变；审批超过库存时显示 409，申请保持待审。
4. `ui4` 登录：资产只读，不显示申请和审批入口。
5. `ui3` 联系人只有社长、主席团、技术部成员；姓名搜索缩小结果、清空恢复。`ui4` 只有社长、主席团、本部门现任部长，不出现宣传部部长。
6. `ui3` 打开 `ui4`：先显示最近 20 条预置历史，「加载更早消息」能看到第 1 条。发送后 `ui4` 从相反方向打开能看到同一消息，回复后 `ui3` 通过轮询收到；刷新重新选择仍能查询记录。
7. `<b>文本</b>` 按纯文本显示；空白、超过 2000 个 Unicode 字符不发送。Enter 发送、Shift+Enter 换行，中文输入法选字不触发发送。轮询不覆盖输入中的草稿。
8. 快速切换联系人 / 返回资产页，旧请求不能插入新会话；切回读取对应历史。退出后不再轮询。
9. `ui7` 登录必须先改密，不能通过演示入口绕过。退出再登录验证新密码。错误密码不建立身份；连续失败 5 次显示锁定与滑块，解锁后仍需重新登录。
10. 后端断开显示连接错误，不回退假数据；发送结果不明不自动重试，核对后才能确认重发。401 返回登录页，403/404 停止当前会话发送。
11. 390px 与桌面宽度检查导航、表格横向滚动和上下分栏聊天布局。

自动测试：`npm test`。后端联系人权限、替换部长、停用、分页和搜索回归位于配套后端 `test/message_contacts_test.go`。
